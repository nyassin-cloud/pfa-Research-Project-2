# pfa-Research-Project-2
For my second research project, I want to create a tool/plugin inside Autodesk Maya that allows users to automatically rig and animate 3D characters using regular videos as references.
The idea is to create a simple GUI where users can select a video from their computer, select their 3D character in Maya, and then use the tool to automatically rig the character and transfer the movements from the video onto it. I don't want the tool to be limited to human characters. I would also like to explore how it could work with different types of characters and creatures, such as four-legged animals, monsters, fantasy creatures, and other non-human models. I want to explore doing this mainly through Maya, Blender, and Unreal Engine.

I personally love animating characters, but I sometimes find the process really difficult and time-consuming, especially when it comes to rigging and creating realistic movements. I know that motion capture already exists, but a lot of professional motion capture equipment, such as suits and specialized cameras, can be expensive and inaccessible to many people.

What I really want to explore is whether I can create a more accessible alternative that allows anyone with a regular video and a 3D character to create animations without needing expensive equipment. 
What I want to show: Ideally, I want to demonstrate the entire process, starting with an unrigged 3D character and a regular video of someone performing an action, and ending with a rigged and animated character.
The Three Weeks:
By December 1: Start building the Maya GUI and get the video and character selection working.
By December 8: Work on automatic rigging and detecting movements from the reference video. Experiment with different character types and figure out how to transfer movement between different skeleton structures.
By December 14: Get the motion transfer working, improve the interface and fix issues with the animation.

If I can't get the entire process working, I would still like to create a Maya tool where users can select a video and an unrigged 3D character, automatically rig the character and apply movement extracted from the video. Even if I can only get it working with one type of character, it would still demonstrate the main idea.

The biggest challenge will be getting the video movement detection to work accurately and transferring that information onto a 3D character's rig andfigure out how to make it work with different character models and body proportions.
